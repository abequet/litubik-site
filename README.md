# litubik.org

Landing page for [LitUbik](https://demo.litubik.org), served by GitHub Pages at https://litubik.org.

Static HTML, no build step: edit `index.html` and push. Every text exists in English and French
(`<span lang="en">` / `<span lang="fr">`); the language follows the browser and the FR/EN button.
Images in `assets/` come from the SoftwareX paper figures.
